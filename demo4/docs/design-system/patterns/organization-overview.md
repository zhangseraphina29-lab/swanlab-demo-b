## 已确定规则

来源：用户于 2026-11-24 在当前任务中的明确要求及两张参考图。

- 用户默认进入组织概览；明确指定的页面入口继续到目标页面。
- 以“成员、项目、使用情况”替换原“可访问项目、组织成员、组织存储”卡片。
- 管理员可见这组卡片，非管理员不可见；现有角色模型的 Owner 和管理员均属于管理者。
- 成员卡包含添加成员入口、成员数量、超级管理员数量和查看成员统计面板入口。
- 项目卡包含创建项目入口、项目数量、进行中的项目及查看项目统计面板入口。
- 桌面成员和项目卡片缩小后在左侧上下排列；使用情况在右侧加宽，高度等于左侧两张卡片加间距的总高度（用户最新修订，取代三张同排）。
- 使用情况展示当前实验人数、运行中的项目、进行中的实验和实验总数。

## 实现记录（不额外冻结设计规则）

- [统计权限与聚合](../../../src/organization-overview.js)：成员数统计 active 成员；超级管理员对应 Owner；项目与实验总数来自当前组织的非回收站项目。
- [React 卡片](../../../src/components/OrganizationOverviewStats.jsx)：成员和项目入口分别复用现有成员管理、项目管理页面；添加与创建入口复用现有表单。
- 当前没有实时执行数据。已有实验时，三项实时指标显示“—”及“实时统计数据暂未接入”；实验总数为零时显示 0。不会从总实验数推测运行状态。
- [局部样式](../../../src/styles/organization-overview.css)：桌面左窄右宽（1:2），成员和项目上下排列，使用情况跨两行；760px 及以下单列，沿用当前语义颜色。
