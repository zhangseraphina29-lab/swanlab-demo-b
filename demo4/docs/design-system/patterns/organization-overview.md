## 已确定规则

来源：用户于 2026-11-24 在当前任务中的明确要求及两张参考图。

- 用户默认进入组织概览；明确指定的页面入口继续到目标页面。
- 以“成员、项目、使用情况”替换原“可访问项目、组织成员、组织存储”卡片。
- 管理员可见这组卡片，非管理员不可见；现有角色模型的 Owner 和管理员均属于管理者。
- 成员卡包含添加成员入口、成员数量、超级管理员数量和查看成员统计面板入口。
- 项目卡包含创建项目入口、项目数量、进行中的项目及查看项目统计面板入口。
- 桌面使用情况、成员、项目从左到右排列，宽度为 3:1:1；页面缩窄时使用情况独占首行，成员和项目在第二行并排，更窄时成员和项目才各自换行（用户 2026-11-25 最新修订）。
- 使用情况展示当前实验人数、运行中的项目、进行中的实验和实验总数。

- 用户于 2026-11-25 要求缩小组织名称，统一缩小概览所有统计卡的字号，与整体界面协调。

- 用户于 2026-11-25 要求取消三张统计卡底部灰块；成员、项目查看入口移至右上角并使用右上箭头图标；添加成员和创建项目使用纯图标按钮。按钮保留原操作及可访问名称。

## 最近更新

用户于 2026-11-25 要求：标题为「最近更新」，默认左侧展示最近更新的项目列表，右侧展示最近更新的实验列表；用户可切换「全部 / 仅项目 / 仅实验」。

实现记录：两列列表在单类型模式下铺满区域，窄屏上下排列；各显示最多 5 项；默认优先展示参与项，同一优先级内按更新时间降序排列，依照当前身份的项目访问权限过滤。实验优先使用已有记录，无逐条记录时沿用项目页已有的项目名 / latest 演示行。点击进入所属项目，暂无独立实验详情页。空项目与空实验分别展示空状态。

用户于 2026-11-25 要求修正显示范围切换控件，并在更新时间左侧增加更新者头像。实现记录：容器 32px、内部按钮 26px，统一 border-box，避免按钮超出容器；项目和实验均使用更新者资料头像，未上传时显示姓名缩写，缺少更新者记录时显示通用人物占位。

## 2026-11-25 最新统计修订

用户要求成员卡辅助信息改为「管理员」数量：当前统计 active 且角色为管理员的成员，不包含 Owner。取代原超级管理员统计展示。最近更新的项目及实验标题右侧分别显示「+数量」。当前数量为访问权限过滤后的最近更新数据条数（截取最多 5 行之前），非某个时间窗口内的新增量；实验沿用现有记录 / latest 演示行。

用户于 2026-11-25 要求：「管理员数量」和「进行中的项目」分别置于成员总数、项目总数下方，并与主数字左对齐。

用户于 2026-11-25 要求成员和项目卡片的主数字至辅助说明间距与使用情况一致；当前统一为 8px。

用户于 2026-11-25 要求：最近更新列表的项目与实验标题 hover 时仅文字变为品牌文字色，不增加底色或下划线；键盘焦点环继续保留。

用户于 2026-11-26 要求使用情况卡片右上角增加刷新图标按钮，保留「刷新使用情况」可访问名称。当前原型重新聚合本地数据并提示「使用情况已刷新（演示数据）」，尚未接入实时服务。

## 最近更新偏好

用户于 2026-11-26 要求：最近更新标题右侧增加设置图标，点击弹窗显示「优先展示我参与的」开关，默认开启。

实现记录：偏好按演示账号保存；开启时优先排列参与项，其他可访问项仍保留，各组内按更新时间降序；关闭时全部按更新时间降序。项目参与判定为创建者或具有直接/权限组显式授权，单纯组织管理权限不计入。实验参与判定为创建者或更新者；缺少这两类身份时沿用项目参与判定。访问权限和统计数量不因偏好改变。

设置按钮沿用图标按钮；弹窗宽 360px，最大宽度为视口减 32px。开关即时生效，保留焦点，无需另行保存。对应：[开关](../reference/switch.md)。
