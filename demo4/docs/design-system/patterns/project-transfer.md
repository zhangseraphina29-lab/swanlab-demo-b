# 项目转移 · Project Transfer

[返回总目录](../README.md)

## 已确定规则

用户于 2026-11-25 指定：转移项目是转移项目所有权及项目权限。选择接收方（组织），并选择是否把项目成员加入接收组织。入口位于项目管理列表的更多菜单，文字「转移项目」。

## 实现记录（不作为额外规则确认依据）

- 使用右侧弹窗选择接收组织，默认不勾选「将项目成员加入接收组织」，确认后执行。
- 沿用现有跨组织操作限制：操作人需同时管理源、目标组织，仅支持同数据区，检查容量、同名和成员名额。
- 勾选时导入项目直接授权名单中的有效源组织成员，保留项目角色；新组织成员角色为贡献者（项目管理/贡献）或查看者（项目查看），已有组织角色保留。已停用目标成员不会自动恢复，邮箱身份冲突报错。相同邮箱的待邀请与新增成员按同一名额计数。
- 未勾选时仅保留接收组织已有有效成员的项目授权。接收组织 Owner 获得项目管理权限，所属组织通过 ownerOrgId 记录；createdBy 保留历史创建者。
- 数据、实验、文件容量及项目标签归属随项目转移，源组织成员身份及历史实验作者记录保留。保持项目可见范围，组织成员可见项目改为向接收组织成员开放。
- 全部检查通过后才修改，失败保留原项目、成员和容量。确认成功后进入接收组织项目管理并清除旧筛选。

## 权限组衔接（2026-11-25 已通过）

权限组限于本组织。转移前说明受影响组，成功转移解除原组的该项目关联，不把原组迁入接收组织。带入成员包含组中有效明确授权成员，按其原明确项目权限转为个人授权；未带入时仅承接接收组织已有有效成员。接收组织重新关联权限组。组变更与项目转移均记录操作者、时间和授权变化。
