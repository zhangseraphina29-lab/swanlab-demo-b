## 已确定规则

来源：[V0.5.3 权限组方案](../sources/permission-groups.txt)顶部最新规则，以及用户于 2026-11-25 通过的本次页面方案。

- 组织管理新增「权限组」，位于成员管理下方。列表包含名称、成员数、授权项目数、最近更新及操作，宽度与成员管理一致。
- 权限组新建与详情页面宽度与组织设置「常规」一致；内容区不重复展示面包屑，顶部导航栏展示「组织 / 权限组 / 新建权限组或组名称」。列表宽度继续与成员管理一致。来源：用户于 2026-11-25 最新页面批注。
- 按用户 2026-11-26 最新要求，左侧同时展示已选成员及已授权项目，右侧提供成员/项目选择面板。成员支持姓名或用户名搜索，项目支持名称搜索；搜索不影响左侧配置。成员可直接移除，项目可直接修改角色或移除。
- 成员表格使用「成员 / 用户名」，显示用户名而非邮箱；名称输入框在标签下方通栏展示，间距收紧。来源：用户本次批注。
- 详情为独立页面，左侧同时展示「组成员」「项目授权」配置，右侧切换选择列表，上方显示「成员通过此权限组获得项目角色授权」及数量，取消二选一的 Tab（用户 2026-11-26 修订）。一个组在不同项目可以使用不同现有角色；本期仅管理、贡献、查看，不提供角色定义及动作勾选。
- 仅 Owner / 管理员维护组；组织治理身份不自动授予项目授权管理权。新增项目、提高默认或成员角色、恢复更高默认角色均检查该项目授权管理权；新增成员检查全部关联项目，任一受限即阻止整次保存并列出受限项目。
- 只允许本组织成员和项目；没有组嵌套，新项目不自动加入。组织查看者可获额外项目授权。个人授权和多个组按允许动作合并。
- 保存前展示成员与项目影响、有效权限变化及变更后的全部来源。移出成员、移除项目、删除组只撤销该来源；保留其他来源、成员身份、项目和实验。
- 加组默认保留直接授权。项目抽屉提供显式「替换直接授权」，预览剩余权限后提交。
- 离开组织清除旧组关系，重新加入不会恢复。停用成员没有有效组权限。
- Free 不提供新增权限组及指定成员项目；付费权益以组织为单位，资源包不解锁。已有授权不因套餐变化直接清空。到期处理细则、价格及组数上限不填写。
- 记录操作者、时间及变更前后内容；可见审计入口按下文「变更记录」实现；保留期仍待定。

## 页面衔接

- 成员列表及详情的权限组数可点击，查看所属组、项目有效角色及全部来源。项目数按明确授权去重，组织默认可见与治理访问不混入明确项目数。
- 项目管理抽屉分「基本信息」「成员与权限」。后者包含直接授权、关联组及有效成员来源；组的管理入口进入组详情。
- 创建项目选「指定成员」后可配置个人及已有组。默认不关联组。
- 跨组织转移解除原组织的组项目关联，接收组织重新关联组；带入成员时包括原组的有效明确授权成员，以个人项目角色承接。

## 实现记录

- 移除模块仅改变界面；此前保存的成员单独角色保留，不自动撤销。未配置成员角色时沿用项目默认值；成员覆盖保存在 `memberProjectRoles`。移出成员、取消关联项目和跨组织转移会清理相应覆盖，项目表单修改默认值保留其他成员的单独设置。
- 用户名优先使用资料或成员的 username；原型尚未填入该字段时沿用现有账号 handle，即邮箱 @ 前的部分。该回退为实现记录。
- `src/permission-groups.js` 统一计算来源、允许动作、成员去重、影响预览及组写入。组织治理管理能力与项目 `authorize` 分开。
- 新建页顺序为名称、授权关系摘要、左侧已配置/右侧选择面板、预览保存；允许保存空组。名称去空格、必填、组织内唯一，上限 80 字符属于本期实现值。
- 页面在现有 React 模板边界内渲染，界面与权限计算分模块；不提供新的通用 React 组件 API。
- 「预览并保存」通过名称表单提交，支持 Enter；名称缺失、重名等错误显示在字段下方并聚焦名称输入框，其他预检错误持续展示在表单中；校验通过后打开影响预览，再确认保存。
- 组草稿在同一页保留；离开未保存详情先确认。保存失败不修改数据，保留草稿。
- 项目表单在副本上校验全部资料、个人授权及组关联，成功后一次提交；新增或撤销来源先预览，返回编辑保留表单。
- 旧 Free 授权保留，支持必要撤销；模型拒绝新增或提高授权。未新增到期计时器或自动清理。
- 可恢复删除的项目保留原组关联；组详情标注回收站，恢复项目后沿用。该项为本期兼容实现记录。
- 原型沿用 org.paid 演示权益；价格及资源额度仍待定，套餐预览改为 Free / Team / Enterprise。

## 权限组回收站

来源：用户 2026-11-26 批注。

- 回收站新增「权限组」Tab，展示删除的权限组，可恢复；项目与实验入口继续保留。
- 删除立即撤销该组来源，快照保留名称、成员、逐项目角色及已有个人角色。恢复前预览影响，确认后重新校验组织管理身份、付费能力、名称冲突及关联项目授权管理权，失败不改变数据。
- 实现记录：恢复排除失效成员与不存在的项目；离开组织和跨组织转移同步清理回收站中的旧关联，避免重新获得已撤销关系。回收站项目保留关联，恢复项目后生效。
- 本次仅提供恢复入口；权限组永久删除及保留期限尚未确定。变更审计记录删除与恢复。
- 分区实现记录：右侧候选列表最多高 420px，内部滚动且表头固定；已选成员自动换行、已授权项目自然展开，不设内部滚动；保持现有页面宽度与语义主题颜色。

实现记录：搜索忽略首尾空白及大小写，候选列表保留已配置项并显示勾选，支持连续勾选或取消；无匹配项与未配置均有文字提示。移除项目会清理对应成员角色覆盖，移除成员清理其覆盖；搜索不会改变草稿，重新打开详情时清空搜索条件。

## 变更记录

来源：用户 2026-11-26 要求所有权限组改动留记录，可用侧边弹窗展示。

- 列表标题的「变更记录」展示当前组织全部组的历史；每行「记录」及编辑页「变更记录」限定当前组。仅组织管理者可查看。
- 右侧抽屉按记录写入顺序倒序展示操作者、年月日时分秒、权限组、操作类型及逐项变化：成员新增/移除、项目关联增减、项目默认角色调整、已有成员个人项目角色调整、名称修改。
- 新建、修改、删除、恢复、成员离开和项目转移均记录；失败或尚未保存的草稿不产生成功记录。恢复显示重新授予的内容，删除显示被撤销的内容。
- 实现记录：新记录使用实际操作时间（ISO），保留操作者 ID、当时姓名、变更前后快照及当时的成员/项目名称；历史旧记录按已有快照推导，没有过去的名称快照时沿用可查资料或 ID，不虚构缺失历史。当前仍随演示数据保存在本地浏览器。
- 间距实现记录：名称表单取消继承的底部横线及 20px 内边距；分区内部统一 12px 间距、原分区之间 28px（最新双栏布局由工作区间距覆盖），说明与标题间 8px；列表单元格上下 10px，勾选行不重复加内边距；搜索框与列表等宽。

代码：[变更内容与历史查询](../../../src/permission-group-history.js)。

- 本次浏览器验证：连续切换勾选状态前后，页面滚动保持 281px、列表滚动保持 273.5px。
