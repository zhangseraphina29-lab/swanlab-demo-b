## 已确定规则

用户于 2026-11-26 指定项目搜索清除叉号为 #594DB9 深紫色、1px 线宽；使用 14px SVG 替换 WebKit 搜索取消按钮外观，保留原生清除行为。

白底描边遮挡修复（2026-11-26）：白色填充仅绘于项目搜索框外层 `.search`，内部 input 保持透明，避免内层背景覆盖内贴聚焦描边。整体视觉仍为纯白搜索框，尺寸、hover 和聚焦防位移规则保留。

用户于 2026-11-26 最新指定：仅所有项目页搜索框容器及输入区底色改为纯白 `#FFFFFF`，其他样式不变；保留边框 hover 加深、深紫聚焦、尺寸与圆角。覆盖此前透明底要求。

用户于 2026-11-26 要求项目搜索框恢复之前透明背景，撤销其纯白背景；其他三个筛选/排序控件仍为纯白，搜索 hover 边框和深紫聚焦效果保留。

用户于 2026-11-26 指定所有项目页工具栏搜索、可见范围、标签筛选及排序四个控件底色为纯白 #FFFFFF，包含 hover；搜索边框 hover 加深、聚焦深紫规则保留。覆盖此前透明背景。

最新用户批注（2026-11-26）：所有项目页搜索框静止且未聚焦时边框颜色与表格/卡片统一，使用 `--border-subtle`；保留 hover 边框加深及聚焦深紫色单层描边。

最新用户要求（2026-11-26）：搜索框未聚焦时 hover 仅加深边框颜色，使用 `border-control` 60% 与 `text-primary` 40% 混合；不改变背景、布局边宽或文字。聚焦优先，保持内贴 1px `#594DB9` 描边，不受 hover 覆盖；内部输入不重复描边。本条覆盖下方“不带 hover”历史规则。

聚焦稳定性修复（2026-11-26）：搜索框聚焦时维持原 `0.5px` 布局边框宽度，边框透明，改用内贴的 `1px solid #594DB9` outline（offset -1px）绘制聚焦描边，避免边宽变化挤动图标及文字。内部输入不重复描边。本实现覆盖下方旧的 1px 实体 border 写法，视觉规格不变。

最新用户批注（2026-11-26）：搜索框聚焦时深紫色 `#594DB9` 描边宽度改为 `1px`，覆盖下方旧 `0.5px` 聚焦规格；未聚焦边框仍为 `0.5px`，内部输入不重复描边。

用户于 2026-11-26 指定所有项目页搜索框所在工具栏整排组件增高 4px：外层高度为 30px，内部输入适配容器内高，其他页面工具栏不受影响。见[尺寸与密度](../foundations/sizing.md)。

用户于 2026-11-26 的项目搜索框批注要求去掉内部灰色底色：`.projects-toolbar .search` 容器与输入框均透明，hover 也保持透明；保留单层深紫聚焦描边。该要求覆盖项目工具栏搜索此前的浅灰背景。

用户于 2026-11-26 指定所有搜索框点击聚焦时使用深紫色 `#594DB9` 描边，宽度沿用 `0.5px`，无额外阴影；带图标的搜索容器通过 `:focus-within` 绘制一层外框，内部输入框不重复描边。搜索框不带 hover 效果，保留原背景及文字，不使用全站浅色 hover 底；适用于工具栏、权限组搜索、全局搜索入口与命令搜索框。本条为后续统一 hover 调整中的独立例外。
