## 成员详情

用户于 2026-11-25 指定：成员详情以右侧抽屉展示，由成员表格行打开，行内已有按钮保持独立操作。实现复用现有原生 dialog 抽屉，支持关闭按钮、Escape 和关闭后焦点恢复。

用户于 2026-11-25 继续指定：成员信息右侧提供与列表一致的更多菜单；角色以选择器编辑；默认不显示底部关闭按钮，修改后右下角显示「取消」「保存」；项目数可点击跳转至该成员的项目管理筛选结果。

实现记录：角色选择只改草稿，取消恢复原值，保存成功后更新成员列表及详情；保存失败保留草稿和错误信息。沿用组织权限限制，Owner 需经原有转移流程交接，角色选择器禁用；管理员不能任免管理员。Owner 的更多菜单三个操作禁用，与成员处置规则一致。普通成员菜单复用列表逻辑；抽屉中的 popover 挂在 dialog 内以支持模态交互。

用户于 2026-11-25 指定：成员抽屉收窄，状态标签、项目数及权限组数与成员列表一致。实现记录：成员详情宽度从 576px 调为 440px，上限为视口宽度；状态复用列表 badge 及尺寸规则，项目数使用相同文字按钮变体，权限组复用数字文字样式。

## 项目管理

用户于 2026-11-25 指定：项目管理列表的「管理」文字按钮打开侧边弹窗。实现复用项目编辑表单，标题「管理项目」，可编辑项目资料、可见范围及成员项目角色。

## 权限组接入

用户于 2026-11-25 通过：项目管理抽屉分「基本信息」「成员与权限」，展示有效角色、全部来源及显式替换直接授权入口。成员详情衔接所属权限组与项目权限来源查看。新增或撤销项目授权保存前展示变化预览，可返回编辑；权限组本体采用独立详情页。详见[权限组](../patterns/permission-group.md)。
