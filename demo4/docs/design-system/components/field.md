- 移除邮箱展示及「地区设置」整块内容（账号国家、公开地区及保存按钮）。

- 原「显示名称」字段名称改为「昵称」，沿用原编辑和保存行为。
- 不再保留空的「身份信息」模块。移除展示不清除已有邮箱或地区数据。
