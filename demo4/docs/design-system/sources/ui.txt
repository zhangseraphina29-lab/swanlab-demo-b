# Demo4 UI 规则

更新：2026-11-24。适用于本地 prototype-demo4；线上版本需要单独授权部署。

## 规则优先级与修改边界

- 用户最新明确要求优先；同一组件旧要求冲突时，以本文件最新规则为准。
- 未要求修改的字号、行高、字重、尺寸、布局、文案和功能保持原状。改配色、动效或图标不得顺带改字号。
- 字号差异先检查 CSS 继承、选择器覆盖及缓存，禁止用全局 button/span/font-size 覆盖解决。
- 页面整体翻译已取消；项目名称、简介和实验室名称使用英文，其他界面保留中文。名称校验沿用既有逻辑。
- 卡片信息层级大改已撤回，不重新引入 22–24px 大标题方案。

## 字号与尺寸基线

| 对象 | 原有规格 / 当前明确要求 |
| --- | --- |
| 工具栏搜索、筛选、排序触发器、按钮 | 26px 高；触发器 12px / 16px |
| 排序菜单选项 | 13px / 20px，字重 450 |
| 全局搜索 | 30px 高、桌面宽 144px、13px 字号；窄屏沿用图标模式 |
| 项目分类标签 | 用户指定统一缩小为 11px / 16px；不扩大作用到正文和菜单 |
| 组织设置导航 | 13px / 20px，与主侧栏一致；桌面宽 220px，与主侧栏展开宽度一致 |
| 访问范围和成员状态标签 | 高度 24px；保持一致 |

其他正文、菜单、表单、标题字号沿用原组件 CSS。不得把表单输入、说明文字及菜单项一律改成工具栏的 12px。

## 配色与主题

- 完整语义 token 见 Project改版/outputs/lucide-colors/usage.md；实现为 lucide-tokens.css、lucide-theme.css。
- Lucide 主红为 #F56565，主按钮配浅色文字。Light/Dark 保持色相，深色 hover/active 降低明度，不能自动偏紫。
- 中性灰使用无彩灰；普通边框轻，控件边框用 border-control，焦点环柔和但清晰。
- 中性状态标签底色为 text-primary 与画布的 10% 混合；深色为 14%。已加入浅绿绿字、已禁用浅红深红字，文案为“已禁用”。
- 单选排序菜单的文字及线性选择图标使用 text-primary，选中与 hover 使用 bg-muted，不使用红色。

## 按钮和图标

- 文字按钮：透明底，hover 加下划线；用于 Alert 操作和表格文字操作。
- 幽灵按钮：hover 浅灰，不加下划线。主侧栏 hover 例外为浅红，静止选中为中性灰。
- 危险操作（包括操作菜单里的删除）用 danger-text 红字，不能被 ghost/text 普通文字色覆盖。
- 全局搜索始终保留与右侧图标相同的 border 描边，hover 不移除，圆角不变。
- 基线社区、官方文档等图标 hover 底色浅红，原有边框、圆角及图标色不变，不加阴影。
- 账号头像 hover 不增加描边或外圈；保留键盘焦点提示。账号菜单只显示实际 ID，不显示 ID: account: 前缀。
- 图标统一 QingIcon 对应语义的线性图标、1.5px 线宽；升级按钮使用指定四芒星 SVG，当前为 outline 样式。
- 组织名 hover 下划线；项目名称 hover 无下划线，各页面项目卡片保持一致。

## 布局与交互

- 组织概览与所有项目采用一致的内容宽度、窄屏边距及卡片断点规则。
- 组织设置侧栏固定，不跟随右侧内容滚动，不参与页面或 Tab 动效；移动端沿用横向换行布局。
- 项目卡片保留信息；去掉底部分割线与 hover 顶部粗红线。更多按钮不旋转，交互反馈限制在按钮边界内。
- 置顶/取消置顶后卡片不移动；更多菜单距省略号 4px，首次显示前完成定位，不闪到远处，不遮挡主要内容。
- 表格标签需要时换行，为编辑图标留空间；实验数量不带实验图标，更新时间去掉“更新于”。
- 重置筛选仅在非默认搜索/筛选时显示；项目数量不带边框。
- Alert 保留块状填充、条纹渐隐、文案左对齐，内容与下方对齐，管理容量默认无下划线。
- 管理标签抽屉新建区始终吸底，列表独立滚动，移除多余横线。
- 侧栏显示控制只显示对齐的图标，可选择固定展开、固定收起、hover 展开。
- 全局搜索聚焦框包住搜索图标与输入区，只保留一层框；输入透明底、占位文字浅。
- 登录页全屏左右结构、左侧交互粒子，保留现有文案；不恢复暂停按钮和演示说明。创建流程头像始终可点击。

## 动效

详见同目录 demo4-motion-guidelines.md。所有 .tabs 共用滑动下划线；内容刷新、搜索筛选及设置侧栏不播放位移 reveal。所有动效支持减少动态效果。
