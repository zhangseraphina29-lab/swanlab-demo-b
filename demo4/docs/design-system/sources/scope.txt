# V0.3.1｜设计目标与边界｜结论

- 状态：已确认，已冻结。
- 编写日期：2026-11-02（北京时间）。
- 整体确认日期：2026-11-02。
- 适用范围：两周设计系统初版，不代表首期产品与商业范围冻结。

## 用户已明确的约束

1. 启动 V0.3.1「设计目标与边界」。
2. 保留 Logo，其他视觉体系可重构；现有绿色、字体与控件风格不作为必须继承项。
3. 使用 Figma，从零建立设计文件。
4. 两周交付设计规范、组件资产与验证样张；工程代码不属于此次选择的交付类型。
5. 延续两周期限、用户工作日约 70% 的投入与逐版确认规则。

## 确定的目标与环境

- 支持 Project 场景的信息层级、内容密度、控件一致性和状态反馈，使后续页面可使用同一套规则与组件。
- 以查找/管理项目的个人使用者、团队参与者为场景视角，尚不将其视为经过调研的用户画像。
- 桌面 Web、浅色优先；1440 px 主验证、1280 px 复核、1024 px 检查伸缩与溢出，均为测试条件。
- 中文界面，覆盖中文、英文、混合长名称和必要数值/单位；完整英文界面不作为本版承诺。

## 确定的首批范围

1. 三类验证场景：项目列表卡片/列表代表区域、创建项目表单、设置分组/现有存储用量。
2. 首批组件约 14 族，按真实使用深度收敛：Button、Input/SearchInput、Field、Select、DropdownMenu、Badge/Tag、Avatar、Card/Section、基本 Table、ViewToggle、Tooltip/完整内容提示、Empty、Skeleton、Alert/InlineFeedback。
3. 组合模式：工具栏、项目展示、表单字段组与提交反馈、设置行与用量摘要/明细。
4. 基础规范覆盖语义色彩、排版、间距尺寸、形状层级、图标、必要动效、桌面布局与可访问性；实际值在后续版本确定。
5. Tabs、Checkbox/Radio/Switch、Dialog、Toast 按样张实际需要再纳入；复杂业务组件、完整 DataTable、暗色与移动端体系、图表、全站接入及品牌全面升级后续扩展。

## 业务与交付边界

- 样张沿用截图已有字段；非零存储测试值等明确标为模拟数据。
- 导航实体、页面合并、角色权限、套餐与付费、字段验证、默认值、容器形态及成功跳转由对应产品版本确定。
- Figma 交付覆盖规范、变量、可复用组件与必要状态、组合模式、验证样张及交接说明；代码映射只作为说明，不等同实现。
- 本版实际交付为下列文档；Figma 资产尚未创建。

## 确定的验收标准

1. 三类场景对应明确目标和组件需求，首批组件均能说明实际用途。
2. 后续样张可复用同一套 Token 与组件，例外有记录；长内容和三种宽度有明确处理。
3. 区分未创建、无结果、零值、加载、失败；表单错误、提交及成功有反馈。
4. 普通文字对比度至少 4.5:1，大文字至少 3:1；必要控件边界与状态提示目标至少 3:1；状态不只依赖颜色。键盘与焦点规则明确，设计检查与实现验收分开记录。
5. Figma 设计完成、规范完成、代码实现各有状态，交付包包含版本、使用规则、映射与后续扩展清单。
6. 用户确认本版整体范围后进入 V0.3.2 产品风格定义；当前不选定风格与 Token 数值。
