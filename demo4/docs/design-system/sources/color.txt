# 常用色与使用规范

基于提供的 Lucide 截图延伸。暂定血红为唯一 danger；原始暗红和莓红仅保留用于方案比较，不进入业务使用。以下 HEX 为浅色主题参考，开发必须引用语义 token，深色主题由 tokens.css 自动映射。

| 角色 | 语义 Token | 浅色值 | 使用场景 |
|---|---|---|---|
| 页面背景 | bg-canvas | #FFFFFF | 应用主画布、内容区域；默认大面积使用。 |
| 次级背景 | bg-subtle | #F6F6F7 | 侧栏、工具栏、分组容器；区分相邻内容区域。 |
| 弱填充 | bg-muted | #EBEBEF | 中性按钮悬停、骨架屏、禁用控件底色。 |
| 分割线 | border-subtle | #E2E2E3 | 卡片分组边框、列表分割线；不作为输入框唯一识别边界。 |
| 控件边框 | border-control | #C7C7CC | 输入框、下拉框、复选框的默认浅灰边界；只略强于分割线，不使用文字灰作为常态描边。 |

| 禁用文字 | text-disabled | #A0A0A7 | 仅用于不可交互控件的文字与图标；不承载必要说明。 |

| 危险 / 错误 | danger-text / danger-bg | #A10B14 / #FFF1F0 | 操作失败、字段校验错误、删除确认中的风险说明。 |

## 组合规则

- 默认使用中性灰；一块操作区域通常只放一个实心主按钮。取消、返回等次要操作用中性背景和主文字。
- 品牌色表示推进与选中，血红表示错误与有损失的操作。主按钮与危险按钮尽量不作为同级相邻操作；删除确认中以危险按钮作为主要动作。
- 状态色只用于状态标签、提示、相关图标与错误字段，不扩散到整个页面。状态底色必须配对应状态文字色。
- 普通链接使用 brand-text 并带下划线或其他可识别线索；不要仅靠颜色传达状态、选中或错误。
- 输入框错误时采用 danger-text 边框，字段下方提供具体错误原因；聚焦时保留独立 focus-ring。
- focus-ring 为 2px，外偏移 3px；不因错误或危险状态移除焦点提示。
- 禁用使用 bg-muted + text-disabled，并在行为上禁止触发；必要的原因说明仍用 text-secondary。
- 主按钮使用 Lucide 主色 #F56565，配浅色 action-text（#FFFFFF）；品牌文字仍使用较深的 brand-text，避免把按钮底色直接用于链接文字。
- 不在业务组件里直接引用 50–900 色阶或硬编码 HEX；引用语义 token。图表、插画等额外色彩需求另行定义。

- 边框保持轻量：卡片和分组使用 border-subtle；可交互控件使用 border-control。默认 1px，不将 text-secondary 或更深文字色用作组件描边，也不因 hover 大幅加深。通过标签、背景和焦点环共同表达可交互性。

## 深色主题

深色主题沿用相同语义 token：主按钮为 #F56565，配浅色文字；hover #DF4549、active #BD303B，逐步降低明度，不使用浅粉闪亮反馈。danger 按钮及提示继续使用独立危险语义。

深色边框同样降低视觉权重：border-subtle 为 neutral-700 与画布按 40% / 60% 混合；border-control 为 neutral-500 与画布按 35% / 65% 混合（OKLCH）。避免直接使用浅色主题的深灰或深色主题的亮灰整圈描边；聚焦继续使用独立品牌焦点环。

## 文字按钮与幽灵按钮

- 文字按钮（text）：用于 Alert 中的操作、表格中的文字操作及轻量链接操作。默认透明底、无边框；hover 仅增加下划线（下偏移 3px），不增加底色、阴影或改变文字颜色。Alert 链接可使用 brand-text，其余通常使用 text-primary。
- 幽灵按钮（ghost）：用于侧边栏导航、组织设置导航及次要工具操作。默认透明底、无边框；hover 使用 bg-muted 浅灰底色，文字颜色保持原有中性色，不加下划线，圆角保持不变。深色模式使用同名 token 映射。
- 表格中的纯图标按钮不套用文字下划线；危险操作仍使用 danger 语义，主要提交仍使用 primary，不能仅因位于表格内而改为普通文字按钮。
- 持续选中态与 hover 分开定义；所有按钮保留独立键盘焦点环与禁用行为。避免将 ghost 类统一映射成 text。

焦点环强度：浅色为品牌主色的 35% 透明度，深色为 coral-300 的 40% 透明度；仍保持 2px、外偏移 3px。降低视觉重量，不移除焦点提示。按钮颜色只作用于 primary，文字按钮和幽灵按钮继续遵循各自的透明底、下划线或中性灰 hover 规则。

危险按钮前景单独使用 danger-action-text：浅色配白字，深色配 #202127；不跟随主按钮的深色文字设置。

## 按钮与深色交互修订

- 主按钮文字统一为 action-text（#FFFFFF），保留 Lucide 主红。浅色文字与该品牌底色的小字号对比低于 WCAG AA，此处按视觉选择使用，不宣称满足正文对比标准。
- 深色模式主按钮：默认 coral-500 → hover coral-600 → active coral-700，明度逐步降低。
- 深色幽灵按钮、图标按钮 hover 使用低明度 bg-muted（neutral-700 与画布按 35% / 65% 混合）；选中品牌浅底使用 coral-900 与画布按 40% / 60% 混合，避免泛白或亮粉。
- Magenta 比较方案深色按钮也改为 500 → 600 → 700；文字按钮仍只加下划线，焦点环保持柔和。

## 色相一致性

Light / Dark 切换只调整明度与必要的饱和度，不改变主色相。Lucide 红的 OKLCH 色相固定为 22.946°，默认、hover、active、选中底色均从同一红色派生；禁止用紫红或莓红替代深色交互态。中性色使用无彩灰（OKLCH chroma = 0），避免暗部呈蓝紫色。深色品牌选中底色由主红 12% 与画布混合，不再使用偏暗莓色作为底色。Magenta 是验证面板主动选择的独立对比方案，不由深色模式自动启用。

导航选中态修订：主侧栏、组织设置侧栏的选中背景统一使用中性 bg-muted，文字 text-primary，不使用品牌混色。红色弱填充使用 sRGB 合成，避免 OKLCH 在有色灰与红之间插值产生紫色。样式发布须更新资源版本，确保旧色值缓存失效。


## 2026-11-24 组件规则修订（本地 demo4）

- 分类标签 `.tag` 在列表、卡片、概览等位置统一 11px / 16px，保持原有颜色及标签高度规则。
- 中性状态标签（等待接受、已移出项目等）使用 text-primary 与画布的 10% 混合底色；深色为 14%，文字 text-secondary。已加入、已禁用及警告状态保留各自语义色。
- 所有 `.tabs` 共用一条 2px 中性下划线，切换时从当前可见位置滑到目标位置；220ms、cubic-bezier(.65,0,.35,1)，只动画 transform。重渲染不得造成下划线闪回；首次出现和普通刷新不播放切换动画。减少动态效果时直接定位。页面内容及组织设置侧栏不参与动效。
- 单选排序菜单的文字、线性选中图标采用 text-primary；选中与 hover 背景 bg-muted，不使用红色。保持文字位置不动。
- 项目操作菜单中的删除使用 danger-text 红字，不能被普通 ghost 或 text 颜色覆盖。
- 组织设置侧栏桌面宽度 220px，与主侧栏展开宽度一致；条目及分组标题恢复紧凑 12px / 20px。760px 及以下沿用横向换行导航，宽度适应容器。
- 主侧栏 hover 为 brand-soft 浅红，选中静止态 bg-muted；图标与文字不因 hover 改色，圆角保持不变。

## 字号与边框维护约束（2026-11-24）

配色修改不得调整字号、字重、行高或组件尺寸。工具栏触发器维持 12px / 16px；排序下拉选项维持 13px / 20px、450 字重。已在所有项目、项目管理和回收站实际浏览器中核对。全局搜索维持 13px，默认和 hover 均保留 1px border-control 描边，不以 focus 环代替常态边框。
