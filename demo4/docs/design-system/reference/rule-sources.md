## 本次整理原则

- 现有明确规则只摘录原文并附来源，不补写新的设计原则、默认值、API、组件选择树或示例。
- 同一规则有明确的后续修订时采用后续内容，例如组织设置导航 13px/20px 取代此前 12px。
- CSS 与控制器仅用于记录实现，不据其存在推断已批准的设计规范。尚无规则的字段留空。
- V0.5.1 的证据要求仅适用于 Supabase 原样参考站，不能将本地 --sb-* 别名说成官方 Token。
- V0.5.2 定价文案和策略明确写有“建议/待确认”，金额、额度、权益未写入已确定规范。仅纳入现有 Demo4 UI 规则明确的弹窗结构与预览边界。
